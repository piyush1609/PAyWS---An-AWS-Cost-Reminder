# Privacy Policy for pAyWS — Spend Jumpscare

**Last updated: August 29, 2026**

pAyWS — Spend Jumpscare is an unofficial Chrome extension that provides local, playful reminders when the user visits selected AWS Console routes.

## Data handling

pAyWS does not collect, sell, share, transmit, or store on developer-controlled servers any personal information, authentication data, AWS account data, billing data, resource data, page contents, browsing history, or analytics data.

The extension examines the current AWS Console page address locally in the browser only to determine whether it matches a supported service route. The address is not sent anywhere.

## Settings

The extension stores only the user's chosen settings—alert enabled state, selected sound, volume, cooldown, and temporary mute time—using Chrome's `storage.sync` API. Chrome may synchronize these settings between browsers signed into the same Chrome profile, subject to the user's Chrome settings and Google's services.

## Permissions

- **AWS Console host access:** Used only to run the on-page alert on AWS Console pages.
- **Storage:** Used only to save the settings listed above.
- **Offscreen:** Used only to play local alert sounds.

## Third parties

pAyWS makes no network requests and uses no third-party analytics, advertising, tracking, or remote code.
