# Sound library

All effects are generated locally with the Web Audio API; no downloaded or third-party audio clips are included.

| Sound | Auto-mode use |
| --- | --- |
| Cash register “cha-ching” 💰 | General fallback / resource creation |
| Cartoon money-drain / coins falling 🪙 | S3 and VPC networking |
| Windows-style error ❌ | Bedrock and expensive-service cues |
| Sad trombone 🎺 | QuickSight and manual selection |
| Air-raid siren 🚨 | EKS and high-cost cluster cues |
| “Oh no!” reaction | Manual selection |
| Dramatic violin sting 🎻 | Manual selection |
| Record scratch 🎵 | Test, sandbox, and staging routes |
| Explosion / boom 💥 | CloudFormation / infrastructure changes |
| Credit-card decline beep 💳 | NAT Gateway and Aurora routes when identifiable |
| Tiny violin 🎻 | Manual selection |
| Game “level up” sound 🎮 | Auto Scaling routes when identifiable |
| Horror movie sting 👻 | Cost Management and Managed Grafana |
| Casino slot-machine win 🎰 | CodeDeploy |
| Crowd gasp 😱 | RDS / Multi-AZ routes |
| Spy-style mission alarm 🚨 | Elastic IP routes when identifiable |
| Generic “two hours later” clock ⏰ | Timestream |
| Dial-up disconnect 📞 | Amazon Connect |
| Evil laugh 😈 | CodePipeline |
| Funeral / church bell 🔔 | Idle or stopped EC2 routes when identifiable |
| Fhaaaa rise | Manual selection |
| Cha-ching | Manual selection |

The service-aware **Auto** option is the default. Every listed sound is also selectable directly from the extension popup.
