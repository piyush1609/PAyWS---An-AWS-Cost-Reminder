# Chrome Web Store listing — pAyWS — Spend Jumpscare

## Name

pAyWS — Spend Jumpscare

## Short description

Playful audio and toast reminders when you open likely billable AWS Console services.

## Detailed description

pAyWS — Spend Jumpscare adds a lighthearted FinOps nudge to the AWS Console. When you navigate to supported AWS services that commonly have usage-based charges, it plays a short sound and shows a sarcastic on-page reminder.

Features:

- Service-aware sounds and jokes for EC2, S3, RDS, Lambda, Bedrock, EKS, DynamoDB, and more.
- Auto sound mode, or choose cash-register, cha-ching, or “fhaaaa” sounds yourself.
- Volume control, repeat cooldown, alert toggle, and a 30-minute mute button.
- Works locally in the browser. No AWS login data, account identifiers, billing data, or page contents are sent to a server.

Important: pAyWS is a humorous awareness tool, not a billing, pricing, budget, or cost-estimation service. It does not determine whether a particular AWS resource is charged, nor does it calculate your AWS costs. Always use AWS Billing and Cost Management for real cost information.

Unofficial tool. Not affiliated with, endorsed by, or sponsored by Amazon Web Services.
